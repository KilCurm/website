# Передача проекта «КУБИКУС» для деплоя

## Что это
Одностраничный лендинг по 3D-печати. Чистый HTML/CSS/JS, без сборки, без npm.

## Где файлы
Весь проект — в этой папке. Точка входа: `index.html`.
Не нужны никакие команды сборки — просто залить папку на хостинг.

## Как деплоить (Netlify / Vercel)
1. Залить содержимое папки в репозиторий (GitHub / GitLab) — или перетащить папку в Netlify Drop / Vercel Dashboard.
2. Netlify: build command — пустой, publish directory — `/` (корень).
3. Vercel: framework preset — «Other», build command — пустой, output directory — `/`.
4. Дождаться деплоя, открыть прод-URL: https://kubicus.ru/

## Что проверить после деплоя (5 минут)
1. `https://kubicus.ru/` открывается, дизайн как на локалке.
2. Favicon «К» виден во вкладке.
3. Burger-меню на мобильном: открывается, ссылки ведут к секциям.
4. Форма: отправить тестовую заявку → success, проверить приход в Formspree dashboard (`https://formspree.io/forms/mkjrgroy`).
5. `https://kubicus.ru/robots.txt` и `/sitemap.xml` открываются.
6. `og:image` открывается: `curl -I https://kubicus.ru/assets/img/og-image.webp` → 200, `image/webp`.
7. Превью в Telegram: кинуть ссылку в «Избранное», проверить карточку.

## Что НЕ трогать
- `KODA.md`, `.kodarules` — внутренняя документация, не для правок.
- `_archive/` — старая версия, не используется (в текущем репозитории папки нет; если появится — не трогать).
- `assets/fonts/` — шрифты, менять только если сломались.
- `robots.txt`, `sitemap.xml` — SEO, менять только с согласованием.
- Папка `assets/` — вся структура уже настроена, пути абсолютные (`/assets/...`).

## Если что-то пошло не так
- **Сайт не открывается** → проверить build settings (должны быть пустыми), publish directory = `/`.
- **404 на CSS/JS/картинки** → проверить, что папка `assets/` залита целиком, пути абсолютные (`/assets/...`), не относительные.
- **Форма не отправляется** → проверить `https://formspree.io/forms/mkjrgroy` (форма активна), DevTools Console/Network.
- **Откатить к предыдущей версии** → `git log --oneline`, найти рабочий коммит, `git reset --hard <hash>`, push, redeploy.
