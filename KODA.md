# КУБИКУС — лендинг

**3D-печать · моделирование · детали**

Одностраничный сайт на чистом HTML/CSS/JS. Без сборки, без npm, без фреймворков.

---

## Обзор проекта

Landing page для бренда «КУБИКУС» — услуги 3D-печати, восстановления деталей, моделирования и изготовления функциональных изделий.

Сайт содержит следующие секции:
- **Header** — навигация + кнопка CTA + burger-меню на `≤1100px` (полупрозрачный с blur, `position: absolute`).
- **Hero** — заголовок, описание, две кнопки CTA, три преимущества (фон: AI-генерация `hero.webp`).
- **Services** — 5 карточек услуг (изготовление деталей, восстановление, печать по модели, моделирование + печать, функциональные изделия).
- **Process** — 5 шагов заказа (от описания задачи до получения изделия).
- **Portfolio («Что можно изготовить»)** — 4 карточки изделий (AI-заглушки `work-1..4.webp`, 800×800, lazy-load).
- **Advantages** — 4 карточки преимуществ (инженерный подход, материалы, опыт, коммуникация).
- **Contact** — форма заявки (имя, телефон/Telegram, описание задачи).
- **Footer** — логотип + контакты (Telegram, телефон, email).

## Сборка и запуск

### Локальный запуск

Только через локальный сервер — из-за абсолютных путей `file://` не работает:

```bash
python -m http.server 8000
```

Открыть: http://localhost:8000 (запускать из корня проекта, где лежит `index.html`).

### Деплой

Автоматический через Netlify / Vercel при пуше в основную ветку.

Прод-URL: https://kubicus.ru/ (`og:url=https://kubicus.ru/`).

## Правила разработки

### CSS

- Все цвета, отступы, радиусы, тени, шрифты — **только через `:root`** в `base.css`. В компонентах — `var(--space-4)`, `var(--red)` и т.п., не голые числа.
- Токены отступов: `--space-1..8` = 4, 8, 12, 16, 24, 32, 48, 64 px.
- Токены радиусов: `--radius-sm/md/lg` = 4, 8, 12 px.
- Тени: `--shadow-sm`, `--shadow-md`.
- Контейнер: `--container: 1240px`.
- Именование — BEM-lite: `.service-card__title`, `.btn--outline`. Утилитарные классы (`.mt-20`) не вводить.
- Медиазапросы — в конце того файла, где живёт компонент.
- `header` и `footer` — самодостаточные, завязаны на `.site-header` и `.site-footer`.
- Header полупрозрачный: `background: rgba(5, 9, 12, .72); backdrop-filter: blur(6px);` — работает при `position: absolute`. Если когда-нибудь сделать `position: fixed` — перепроверить читаемость на светлых секциях.

### JS

- Каждый файл — IIFE с проверкой наличия целевого элемента:

```js
(function () {
    var el = document.querySelector('...');
    if (!el) return;
    // ...
})();
```

- Скрипт не падает на странице без этого элемента.
- `nav.js` — плавный скролл по якорям (`scrollIntoView({ behavior: "smooth" })`).
- `form.js` — отправка в Formspree через `fetch` + `FormData`. Кнопка-индикатор: «Отправка…» → «Готово!» (зелёная, форма сбрасывается) / «Ошибка» (красная, форма не сбрасывается) → через 3 с возврат к исходному виду. `aria-live="polite"` на кнопке.

### Картинки

- Все рабочие картинки — **WebP**. JPG/PNG/др. — только как источник, в репозиторий не класть.
- Пути в CSS и HTML — абсолютные: `/assets/img/...`.
- Hero и contact используют **один и тот же** `hero/hero.webp` (в `components.css` через `background-image`).
- Портфолио (`work-1..4.webp`) — `<img>` с `width="800" height="800"`, `loading="lazy"`, `decoding="async"`. Кроп 1:1 (`aspect-ratio: 1 / 1` + `object-fit: cover`).
- AI-фото портфолио — **временные заглушки**. Заменить на реальные фото при появлении.

### Иконки (SVG)

- Единый спрайт `assets/img/icons.svg` с `<symbol>`. Подключение: `<svg><use href="/assets/img/icons.svg#icon-name"></use></svg>`.
- Все `viewBox="0 0 24 24"`. Цвет захардкожен внутри файла.
- Все иконки декоративные — `aria-hidden="true"`.

### Добавление новой страницы

1. Скопировать `index.html` → `newpage.html`.
2. Обновить `<title>`, `<meta description>`, OG-теги.
3. Подключить те же 4 CSS в том же порядке и те же 2 JS с `defer`.
4. Удалить ненужные секции, оставить нужные.
5. Переопределения — только в `pages.css`.
6. Ссылку на новую страницу добавить в `<nav>` шапки **и** в `<nav class="mobile-menu__nav">`. Обе копии обязательны.
